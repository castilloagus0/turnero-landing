# Turnate design system

Turnate should feel premium, minimal, technological, cinematic, sophisticated, and modern. Its core palette is `#02050A`, `#061328`, `#1F6FFF`, `#47A3FF`, `#8AC7FF`, and `#F5F7FA`. Avoid generic SaaS aesthetics.

The illuminated Earth represents the Turnate ecosystem. Its nodes stand for appointment-based businesses: barbershops, hair salons, beauty and aesthetics centers, consultories, health professionals, spas, wellness businesses, and other reservation-based commerce. Do not use the planet arbitrarily; it should communicate:

`Turnate → different businesses → one ecosystem → centralized appointment management`.

Before introducing a new visual style, inspect existing components and references, then confirm it fits the current visual language. Prefer coherence over adding new effects.
